# yelp-lv-spatial

Análisis espacial de restaurantes en Las Vegas usando datos Yelp (2015–2017).

## Estructura

```
yelp-lv-spatial/
├── data/          # Archivos fuente (solo lectura)
├── scripts/       # Scripts numerados, autocontenidos
│   ├── 01_data_prep.R
│   ├── 02_spatial_layers.R
│   ├── 03_sentiment_analysis.R
│   ├── 04_attribute_ops.R
│   └── 05_app.R
├── outputs/       # Objetos .rds exportados por cada script
└── README.md
```
